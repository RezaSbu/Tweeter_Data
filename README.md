# Tweeter Data Analysis 🐦

Statistical analysis of a **Twitter dataset on harassment of women in Iran**.

## Overview

A comprehensive quantitative study of tweets related to the harassment of women in Iran. The analysis combines statistical hypothesis testing, machine learning classification, and time-series methods to extract insights from the dataset.

## Methods Used

- **Hypothesis testing:** chi-square, Mann-Whitney U, proportion z-test, Bonferroni correction
- **Classification:** precision / recall / F1, confusion matrix
- **Time-series:** changepoint detection (CUSUM + moving average), trend projection (linear + quadratic)
- **NLP:** context-aware toxicity scoring with negation detection, gender inference with confidence scores
- **Correlation:** Spearman, logistic / linear regression
